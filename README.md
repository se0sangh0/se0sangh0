# 서상호 | Game & System Planner

게임에서 출발해 보안·산업 모니터링·IoT·AI·웹까지, 문제를 규칙과 데이터로 풀어내는 기획자입니다.  
아이디어를 문서에 남기는 데서 멈추지 않고, 구현 가능한 구조로 정리해 실제 빌드와 운영 흐름으로 검증하는 일을 좋아합니다.

## 주요 프로젝트

- **[게임·시스템 기획 포트폴리오](https://se0sangh0.github.io/portfolio/)**  
  대표 프로젝트와 제가 맡은 부분, 수상·활동을 한 번에 볼 수 있습니다. 최신 PDF는 페이지 우측 상단의 저장 버튼으로 만들 수 있습니다.

- **[괴이탐사국](https://github.com/se0sangh0/inspector)**  
  팀578의 팀장·기획 총괄로 진행 중인 다크 호러 로그라이크 덱빌딩 오토배틀러 프로젝트입니다.

- **ThermoGuard**  
  열화상 모니터링 팀 프로젝트에서 통합 GUI, GigE 카메라 연결, FastAPI·DB·데이터 흐름 정리와 Linux 실행·패키징 구조 구성을 진행했습니다.

- **ESP32-S3 빗물받이 수위 경보**  
  리빙랩 현장 조사 후 플로트 센서 2개와 RGB LED·부저를 이용한 단계 경보 시제품을 설계·제작하고 상태 전환을 검증했습니다.

- **[Game Design Document](https://github.com/se0sangh0/Game_Design_Document)**  
  2D 횡스크롤 액션 게임의 학습·수중·공중·보스 스테이지를 시스템과 레벨 흐름 중심으로 정리한 기획 문서입니다.

- 개발·데이터 — Unity, C#, Python, FastAPI, MariaDB, ESP32-S3, ROS2
- 문서화·협업 — 구현 기준이 되는 기획서, 데이터 구조, 일정·QA 정리

현재는 **괴이탐사국 프로토타입**, **ThermoGuard 모니터링**, **IoT·ROS2 프로젝트 학습**을 중심으로 작업하고 있습니다.
